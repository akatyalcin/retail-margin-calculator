# 📊 Retail Margin & Inventory Calculator

A modern, bilingual (English/Turkish) desktop application designed to streamline retail operations. It quickly calculates key financial metrics including gross profit, profit margins, and total inventory valuation based on unit cost and retail price.

## 🚀 Features
- **Bilingual Interface:** Real-time language switching between English and Turkish.
- **Financial Analytics:** Calculates gross profit per item, profit margin percentage, and total retail value of stock.
- **Modern UI:** Built with CustomTkinter for a sleek, dark-mode user experience.

## 🛠️ Technologies Used
- **Language:** Python 3.x
- **GUI Framework:** CustomTkinter

## ⚙️ How to Run
1. Clone this repository to your local machine.
2. Install the required UI library by running: `pip install customtkinter`
3. Run the application: `python calculator.py`
